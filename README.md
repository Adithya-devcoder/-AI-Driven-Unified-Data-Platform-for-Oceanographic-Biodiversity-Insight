# AI-Driven Unified Data Platform for Oceanographic Biodiversity Insight

This project is a sophisticated dashboard for visualizing oceanographic data, biodiversity, and climate impacts using React, Deck.gl, and MapLibre.

## Project info

A comprehensive platform for monitoring ocean health, marine species distribution, and environmental risks.

## How to Run Locally

To work on this project locally, ensure you have Node.js and npm installed.

```sh
# Step 1: Clone the repository
git clone https://github.com/Adithya-devcoder/-AI-Driven-Unified-Data-Platform-for-Oceanographic-Biodiversity-Insight.git

# Step 2: Navigate to the project directory
cd Ocean

# Step 3: Install dependencies
npm i

# Step 4: Start the development server
npm run dev
```

## Technologies Used

This project is built with:

- **Vite**: Next-generation frontend tooling
- **TypeScript**: Static typing for JavaScript
- **React**: UI library
- **Deck.gl**: WebGL-powered framework for visual exploratory data analysis of large datasets
- **MapLibre GL**: Open-source map rendering
- **shadcn-ui**: Reusable components built with Radix UI and Tailwind CSS
- **Tailwind CSS**: Utility-first CSS framework

## Features

- Interactive 3D Risk Maps
- Real-time Ocean Metrics
- Biodiversity and Marine Species Tracking
- Climate Impact Analysis
- Pollution Monitoring
